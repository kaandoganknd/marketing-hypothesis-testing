# Marketing Hypothesis Testing

Exploratory analysis of customer profile, income and product-spending data, with three non-parametric hypothesis tests.

## Questions

1. Do household-income distributions differ between PhD and Master's education groups?
2. Is household income monotonically associated with total product spending?
3. Is education associated with a simplified marital-status group?

## Method

The notebook checks the supplied data, removes one extreme income record, uses K-nearest-neighbours imputation for 24 missing income values, and runs Mann–Whitney U, Spearman rank-correlation and chi-square tests at a 0.05 significance level.

## Repository contents

- `notebooks/marketing_hypothesis_testing.ipynb` — executed analysis and test outputs
- `data/Marketing_data.csv` — supplied input data
- `images/` — charts generated by the notebook

## Run locally

```bash
pip install -r requirements.txt
jupyter notebook notebooks/marketing_hypothesis_testing.ipynb
```

The data are a supplied snapshot. Findings are descriptive and should not be read as causal conclusions.
